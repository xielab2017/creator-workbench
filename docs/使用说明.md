# 创作管理工作台

首次打开左侧「创作管理工作台」图标，选择保存目录并点击「创建并打开」。初始化会补齐六个页面、模板、备用表格和横幅，跳过已有文件。7 篇演示作品可选，默认不加入。

1. 工作台：设置月度目标，查看真实作品表现和下一步行动。
2. 选题池：收集灵感，拆解参考，并填写自己的切入点。
3. 创作台：拖动作品推进选题、写稿、录制、剪辑、待发布、待复盘和已归档阶段。图文可以跳过录制和剪辑。
4. 日历：点击日期新建排期；拖动改期只改计划日期，保留制作阶段。已发布作品按实际发布日期展示。
5. 作品库：同一篇笔记保存标题、正文、视频、素材与发布链接。
6. 数据库：录入平台后台真实指标与账号快照，并记录复盘证据。

制作清单记录细分任务，阶段由卡片或属性维护。进入待复盘需核对实际发布日期，归档还需填写完成复盘日期。未观察的指标留空，不用 0 替代。演示作品不计入真实目标、业绩或日历同步。

## iCloud 与 Mac Calendar

先在 Mac Calendar 的 iCloud 账户下建立「创作排期」。进入 Obsidian 设置 → Creation Studio，填写账号、应用专用密码、服务器和日历名称，保存后测试连接。测试成功后再开启自动同步。

方向：作品笔记 → iCloud「创作排期」→ Mac Calendar。Full Calendar 可由用户另行配置为读取同一日历。本插件不读取或修改 Full Calendar 的设置和密码。

日历服务会收到账号认证，以及作品标题、平台、阶段、日期、唯一标识和笔记链接；链接含知识库名称与文件路径。正文、媒体、作品指标不发送。密码保存于本插件独立的 Obsidian SecretStorage 条目。

日历修改不回写作品。没有时间为全天事件，有时间为 30 分钟提示，均按北京时间；已发布作品只用实际日期全天展示。Obsidian 关闭时不执行同步。停用插件后笔记与已有云端日程保留。

原本使用本地模板包的用户无需重导模板。版本 2 会暂停旧日历连接；请在本插件内重新配置并启用。当前仅支持 Obsidian 桌面版 1.14.4 及以上。
