## Short description

Manage ideas, production, publishing schedules and reviews in linked notes, with optional one-way iCloud calendar sync.

## Listing description

Creation Studio connects ideas, production, publication scheduling and review through one Markdown note per work. Initialize a six-page workspace with a dashboard, idea pool, production board, monthly publication calendar, work library and metrics view. The setup includes local templates, optional demonstration notes and a bundled original banner, and skips existing files.

Track detailed production checklists, stage, next action, deadlines, drafts, finished-media links, actual publication dates and review evidence. Missing performance metrics remain missing. Demonstration works are excluded from real totals and calendar sync.

The core workflow is offline and requires no account or other community plugin. Optional, explicitly enabled iCloud CalDAV sync sends publication schedule fields to a dedicated calendar that Mac Calendar can display. Full Calendar can be configured separately to show the same calendar. Credentials use a plugin-owned Obsidian SecretStorage entry. The plugin does not read or modify Full Calendar's credentials or configuration.

Current interface language: Chinese. Desktop Obsidian 1.14.4 or later. See the repository README for network disclosures, privacy details and tested scope.
